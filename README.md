# PythonPandas-Projects
Python Pandas projects completed during the Leep Talents Data Skills Bootcamp, showcasing data cleaning, manipulation, filtering and analysis.
# About This Repository

This repository showcases my Python Pandas coursework completed during Week 6 (Days 3 and 4) of the Leep Talents Data Skills Bootcamp.

The exercises focus on using Python and the pandas library to explore, clean, manipulate and analyse structured datasets. Through practical coding tasks, I developed my understanding of how Python can be used to process information, identify patterns and support data-driven decision-making.

# Skills and Techniques

Data Exploration: Importing datasets into pandas DataFrames and examining their structure and contents.

Data Selection: Using .loc[] and .iloc[] to select specific rows and columns.

Data Filtering: Applying conditional statements and Boolean masking to retrieve relevant records.

Data Manipulation: Using methods such as sort_values() and groupby() to organise and summarise data.

Data Cleaning: Exploring methods such as dropna() and fillna() to handle missing values.

Data Analysis: Performing calculations and extracting useful information from datasets.

Data Visualisation: Using Python plotting tools to explore and communicate patterns, where applicable.
